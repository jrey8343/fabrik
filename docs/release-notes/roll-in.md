# Release notes: The Roll-in

The notes for the release that ships the Roll-in ([#595](https://github.com/jrey8343/fabrik/issues/595), under ADR-0010): a Design session on an issue filed from a pull request is told about that pull request, and can finish by settling a Roll-in onto it, which only the Operator sends. Paste them into the release's notes file (see [releasing.md](../releasing.md)), with its version and pins.
